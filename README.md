# 📅 Telegram-бот для уведомлений из Google Calendar

Асинхронный Telegram-бот на базе `aiogram` и `APScheduler`, который интегрируется с Google Calendar API и отправляет пользователям уведомления о предстоящих встречах за настроенное время.

## ✨ Особенности проекта
- **Безопасность:** Токены пользователей шифруются алгоритмом Fernet (`cryptography`) перед сохранением в базу данных. Конфиденциальные данные проекта вынесены в переменные окружения.
- **Интерфейс:** Удобное управление через нативное синее меню Telegram-команд.
- **История встреч:** Бот отслеживает и выводит список последних 10 полностью завершенных событий.
- **Стабильность:** Поддержка режима WAL в SQLite для безопасной многопоточной работы планировщика.

## 🛠️ Инструкция по развертыванию

1.**Клонируйте репозиторий:**
   git clone https://github.com/Pro100sashaHD/TelegramNotificationBot
   
   cd TelegramNotificationBot

2.**Настройка виртуального окружения:**
    # Для Windows
    
    python -m venv .venv
    
    .venv\Scripts\activate
    
    # Для Linux / macOS
    
    python3 -m venv .venv
    
    source .venv/bin/activate

3.**Установка зависимостей**

   pip install -r requirements.txt
   
4.**Настройка секретов**
  #Windows
  
  copy example.env .env

  #Linux / macOS
  
  cp example.env .env
5.**Получение credentials.json от Google**
 Перейдите в Google Cloud Console.
 
 Создайте проект и включите Google Calendar API. 
 
 Настройте OAuth Consent Screen (в режиме Testing добавьте ваш рабочий Google-аккаунт в Test Users).
 
 В разделе Credentials создайте Ключ доступа: OAuth client ID (Тип приложения: Desktop app).
 
 Скачайте полученный JSON-файл, переименуйте его строго в credentials.json и положите в корень папки проекта.
 
🕹️ **Использование бота**

Запустите проект main.py

Доступные команды в меню:/start — Инициализирует пользователя в базе данных и генерирует уникальную ссылку для авторизации в Google-аккаунте. В ответ на сообщение бот ожидает код авторизации, скопированный из браузера.

/set_reminder <минуты> — Устанавливает персональное время для заблаговременного получения уведомлений (например: /set_reminder 15).

/history — Выводит список из 10 последних встреч, время окончания которых уже наступило.  

🔒 Безопасность данныхПроект разработан с учетом строгих требований к конфиденциальности:  Конфиденциальные файлы (.env, credentials.json, bot_database.db, файлы логов) внесены в .gitignore и никогда не попадут в публичный доступ.  

Данные авторизации пользователей (refresh_token и access_token) шифруются криптостойким алгоритмом AES в режиме CBC с использованием HMAC для аутентификации (библиотека cryptography), что исключает компрометацию данных даже при прямой утечке файла базы данных.
